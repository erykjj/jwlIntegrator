# *JW Library* roll-back guide for Android

Read this through first to make sure you understand all the steps:

**Goal:** To download and install an older version of *JW Library* (v15.6.1) in order to install custom JWPUB archives on an Anroid device. Once the custom JWPUB files are installed, *JW Library* can be updated to the latest version, while the custom JWPUBs remain in the app.

**Difficulty:** Easy.

**Duration:** About 20 to 30 minutes.

**Important:** The process involves re-installing *JW Library*, so you will need to re-download all your Bible, publications, videos, etc.

1. **Backup your data**
  - ⚠️ **IMPORTANT:** Before proceeding, **make sure to make a backup of your personal *JW Library* data** (notes, highlights and playlists). Go to *Personal Study → Create Backup*.

2. **Download [*JW Library* v15.6.1](https://www.apkmirror.com/apk/jehovahs-witnesses/jw-library/jw-library-15-6-1-release/)**

3. **Uninstall and reinstall**
  - ⚠️ **IMPORTANT:** Make sure you have successfully completed the backup described in step #1.
  - Uninstall the current version of *JW Library* from your device
  - Install the downloaded APK file
    - You will be starting from scratch with no data — this is expected

4. **Install all the JWPUBs you need/want**
  - You can install them normally/as before (without *jwlIntegrator*)

5. **Update to the latest version**
  - Let the Play Store update the *JW Library* app

6. **Restore your personal data**
  - Once you are on the latest version, restore your backup: *Personal Study → Restore Backup*

7. **Redownload all your official Bibles, publications and videos**
